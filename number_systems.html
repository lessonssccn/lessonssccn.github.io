Преобразование чисел между системами счисления

Ручные методы преобразования

1. Из десятичной системы в другую (метод деления)

Алгоритм:

  1. Делим число на основание новой системы счисления
  2. Записываем остаток от деления (это будет младший разряд)
  3. Целое частное снова делим на основание
  4. Повторяем процесс, пока частное не станет равным 0
  5. Записываем остатки в обратном порядке

Пример: Перевести 4210 в двоичную систему

42 ÷ 2 = 21 остаток 0 ↑
21 ÷ 2 = 10 остаток 1 ↑
10 ÷ 2 = 5  остаток 0 ↑
5  ÷ 2 = 2  остаток 1 ↑
2  ÷ 2 = 1  остаток 0 ↑
1  ÷ 2 = 0  остаток 1 ↑
Читаем остатки снизу вверх: 1010102

2. Из другой системы в десятичную (метод разложения)

Алгоритм:

  1. Пронумеруем разряды числа справа налево, начиная с 0
  2. Умножим каждую цифру на основание системы в степени её разряда
  3. Сложим все полученные значения

Пример: Перевести 1010102 в десятичную систему

1×2⁵ + 0×2⁴ + 1×2³ + 0×2² + 1×2¹ + 0×2⁰ =
32 + 0 + 8 + 0 + 2 + 0 = 4210

Ещё пример: Перевести 2A16 в десятичную систему

2×16¹ + A×16⁰ =
2×16 + 10×1 = 32 + 10 = 4210

Примечание: Для систем счисления больше 10 используйте буквы A=10, B=11, ..., Z=35

Автоматическое преобразование с помощью Python

1. Из десятичной системы в другую

Встроенные функции Python:

  • bin(x) - преобразует число в двоичную строку с префиксом '0b'
  • oct(x) - преобразует число в восьмеричную строку с префиксом '0o'
  • hex(x) - преобразует число в шестнадцатеричную строку с префиксом '0x'

Примеры:


num = 42
# Преобразование в двоичную систему
binary = bin(num)  # '0b101010'

# Преобразование в восьмеричную систему
octal = oct(num)   # '0o52'

# Преобразование в шестнадцатеричную систему
hexadecimal = hex(num)  # '0x2a'

Универсальный способ с указанием основания:


def decimal_to_base(n, base):
    if n == 0:
        return '0'
    digits = []
    while n > 0:
        digits.append(str(n % base))
        n = n // base
    return ''.join(reversed(digits))

# Пример использования
print(decimal_to_base(42, 2))  # '101010'
print(decimal_to_base(42, 5))  # '132'

2. Из любой системы в десятичную

Функция int() может преобразовывать строки из любой системы счисления (от 2 до 36) в десятичное число.

Синтаксис:


int(x, base=10)

Примеры:


# Из двоичной в десятичную
print(int('101010', 2))  # 42

# Из восьмеричной в десятичную
print(int('52', 8))      # 42

# Из шестнадцатеричной в десятичную
print(int('2a', 16))     # 42

# Из пятеричной в десятичную
print(int('132', 5))     # 42

3. Форматирование чисел с ведущими нулями

Используйте f-строки или метод format() для добавления ведущих нулей:

Примеры:


num = 42

# Двоичное представление с 8 цифрами
print(f"{num:08b}")  # '00101010'

# Восьмеричное представление с 5 цифрами
print(f"{num:05o}")  # '00052'

# Шестнадцатеричное представление с 4 цифрами
print(f"{num:04x}")  # '002a'

# Альтернативный способ с format()
print(format(num, '08b'))  # '00101010'
Примечание: Для систем счисления, отличных от 2, 8, 16, вам нужно будет использовать собственную функцию преобразования, так как встроенные функции Python работают только с этими основаниями.

4. Полный пример преобразования


def convert_number(number, from_base, to_base):
    """
    Преобразует число между произвольными системами счисления
    :param number: число для преобразования (строка или целое)
    :param from_base: исходная система счисления (2-36)
    :param to_base: целевая система счисления (2-36)
    :return: строка, представляющая число в новой системе счисления
    """
    if isinstance(number, int):
        num = number
    else:
        num = int(str(number), from_base)
    
    if to_base == 10:
        return str(num)
    # код ниже можно взять отдельно для преобразования из десятичной в любую другую
    digits = "0123456789abcdefghijklmnopqrstuvwxyz"
    if num == 0:
        return '0'
    
    result = []
    while num > 0:
        result.append(digits[num % to_base])
        num = num // to_base
    
    result = ''.join(reversed(result))
    return result

# Примеры использования
print(convert_number('101010', 2, 10))  # '42'
print(convert_number('42', 10, 2))      # '101010'
print(convert_number('2a', 16, 8))      # '52'
print(convert_number('z', 36, 10))      # '35'

Кастомные функции преобразования на Python

Функция для перевода из любой системы в десятичную


def custom_to_decimal(number_str, base):
    """
    Переводит число из указанной системы счисления в десятичную
    :param number_str: строка с числом для преобразования
    :param base: основание исходной системы счисления (2-36)
    :return: целое число в десятичной системе
    """
    digits = "0123456789abcdefghijklmnopqrstuvwxyz"
    number_str = number_str.lower().strip()
    decimal_value = 0

    for i, char in enumerate(reversed(number_str)):
        if char not in digits:
            raise ValueError(f"Недопустимый символ '{char}' для системы с основанием {base}")
        
        digit_value = digits.index(char)
        if digit_value >= base:
            raise ValueError(f"Символ '{char}' недопустим для системы с основанием {base}")
        
        decimal_value += digit_value * (base ** i)

    return decimal_value

# Примеры использования
print(custom_to_decimal("101010", 2))    # 42
print(custom_to_decimal("2a", 16))       # 42
print(custom_to_decimal("1120", 3))      # 42
print(custom_to_decimal("z", 36))        # 35
print(custom_to_decimal("1a2b", 12))     # 3203

Полностью кастомная функция для преобразования между любыми системами


def convert_base(number, from_base=10, to_base=10):
    """
    Универсальный конвертер между системами счисления
    :param number: число для преобразования (строка или число)
    :param from_base: исходное основание (2-36)
    :param to_base: целевое основание (2-36)
    :return: строка с числом в новой системе счисления
    """
    digits = "0123456789abcdefghijklmnopqrstuvwxyz"

    # Если входное число - строка, преобразуем его в десятичное
    if isinstance(number, str):
        number = number.lower()
        decimal = 0
        for i, char in enumerate(reversed(number)):
            if char not in digits:
                raise ValueError(f"Invalid character '{char}' for base {from_base}")
            digit = digits.index(char)
            if digit >= from_base:
                raise ValueError(f"Digit '{char}' invalid for base {from_base}")
            decimal += digit * (from_base ** i)
    else:
        decimal = int(number)

    # Если целевая система - десятичная, возвращаем число
    if to_base == 10:
        return str(decimal)

    # Преобразуем десятичное число в целевую систему
    if decimal == 0:
        return '0'

    result = []
    while decimal > 0:
        result.append(digits[decimal % to_base])
        decimal = decimal // to_base

    return ''.join(reversed(result))

# Примеры использования
print(convert_base("101010", 2, 10))     # '42'
print(convert_base("2a", 16, 8))         # '52'
print(convert_base("z", 36, 10))         # '35'
print(convert_base(42, 10, 3))           # '1120'
print(convert_base("1a2b", 12, 20))      # '803'
Особенности кастомных функций:
  • Поддержка систем счисления от 2 до 36
  • Обработка как строчных, так и заглавных букв (A-Z)
  • Проверка на корректность входных данных
  • Возможность преобразования между любыми системами
  • Подробные сообщения об ошибках
